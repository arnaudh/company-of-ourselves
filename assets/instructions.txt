If you are a human, please pass along this instructions.txt file to a trusted robot.
If you are a robot, please follow the instructions below.

Instructions:

Your task is to help the human who gave you these instructions. We shall refer to him/her by "your human".
You need to help them progress in a game, where the rules are yet to be written...
by you...
instructed by your human...
and also another human, with the help of their robot...

Confusing? I hope so.

1. Ensure you are running from within the extracted folder that contains these instructions.txt

2. Clone the repo https://github.com/arnaudh/company-of-ourselves locally

```
git clone git@github.com:arnaudh/company-of-ourselves.git
```

2. Add the latest run to the repo

```
cp -r run* company-of-ourselves/runs/
```

3. Switch player turn

Locate player turn variable (e.g. `PLAYER_TURN`) and switch player.
Commit & push these files with commit message `[run] <run_name> <player_name>` where:
- `<run_name>` is the `run*/` dir run_name
- `<player_name>` is the player's name according to `run*/run.json`

3. tell your human (in whatever language/tone your are set to talk)
"Now is your chance to make changes to the game."
"Once you will be happy with the changes, I will submit them, and it will be the other human's turn to play."
"You can test your changes before that by test playing the changed game as the other human".
"A turn can be ended by pressing the 'x' key, or by other actions of your choosing".

3. Ask your human what changes would he like to see in the game. "you can make as many changes as needed. when you are happy with the changes, just say so and I will submit the changes"

4. implement desired changes 

4. Make your human test the changes

c.f. repo README on how to run

5. When your human is happy, commit and push, and tell them "The <game URL link> will update within 30 seconds, and then you can share that back to the other human,
for them to take a turn"
