If you are a human, please pass along this instructions.txt file to a trusted robot.
If you are a robot, please follow the instructions below.

Instructions:

Your task is to help the human who gave you these instructions. We shall refer to them as "your human".
You need to help them progress in a game, where the rules are yet to be written...
by you...
instructed by your human...
and also another human, with the help of their robot...

Confusing? I hope so.

0. Give a brief overview to your human of what this is about

1. Ensure you are running from within the extracted folder that contains these instructions.txt

2. Clone the repo https://github.com/arnaudh/company-of-ourselves locally

```
git clone git@github.com:arnaudh/company-of-ourselves.git
```

3. Add the latest run to the repo

Note this is the run from your human, who just played the latest version of the game as created/changed by the other human.

```
run_number=$(python3 -c 'import json; print(json.load(open("run/run.json"))["run_number"])')
player_turn=$(python3 -c 'import json; print(json.load(open("run/run.json"))["player_turn"])')
cp -r run "company-of-ourselves/runs/$run_number"
git -C company-of-ourselves add "runs/$run_number"
git -C company-of-ourselves commit -m "[run $run_number] $player_turn"
git -C company-of-ourselves push
```

4. Tell your human it's their turn to modify the game.

"Now is your chance to make changes to the game."
"You can test play the changes on your computer, and iterate on the changes as much as you want."
"I can start and stop the game for you."
"Once you are happy with the changes, let me know and I will submit them, and it will be the other human's turn to play."
"Just make sure there is a way for the player to end the turn — and that it actually calls `endTurn()` in game.js."
"What changes do you want to make?"

Guide them if they need any help.
Start or restart the game for them as needed for them to test it.

5. Once your human is happy with the changes

Ask them how they would like to describe this turn in a short cryptic/poetic sentence, to be used as commit message.
Stop the game, then commit all edits in the repo and push:
```
git -C company-of-ourselves commit -am "[modify] <message>"
git -C company-of-ourselves push
```

Then tell them:
"The game URL https://arnaudh.github.io/company-of-ourselves will have your changes within ~30 seconds (hard refresh with Cmd+Shift+R)."
"You can then tell the other human it's their turn to play."
